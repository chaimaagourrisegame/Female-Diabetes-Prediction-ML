# Predicting Diabetes in Female Patients
A machine learning project comparing models to predict diabetes outcomes.

## Problem
We want to predict wether a female patient has diabetes (1) or not (0). 
## Data Source
Dataset downloaded from kaggle: https://www.kaggle.com/datasets/hasibur013/diabetes-dataset

## Project Steps
- Problem Definition
- Data Understanding
- Exploratory Data Analysis
- Data Preprocessing
- Machine Learning: Model training
- Evaluation and Model Comparison
- Cross-Validation
- Reducing Overfitting
- Conclusions and Limitations

- This project is a personal project made with the help of AI tools in order to review code, understand the methodology and problem solving steps in machine learning projects
